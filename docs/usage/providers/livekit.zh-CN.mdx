# 在 LobeHub 中使用 LiveKit Inference

[LiveKit Inference](https://docs.livekit.io/agents/models/inference/) 通过一个 LiveKit Cloud 项目提供语言模型、语音识别和语音合成服务。用量由 LiveKit Cloud 计费；请查看[最新价格](https://livekit.com/pricing)和项目可用的模型。

1. 登录 [LiveKit Cloud](https://cloud.livekit.io)，获取项目的 API Key 和配套的 API Secret。
2. 打开 **应用设置 → AI 服务商 → LiveKit**，填写 **API Key** 和 **API Secret**，再启用服务商。凭证会自动保存。
3. 在内置模型列表中启用所需模型。点击 **检查** 验证语言模型请求。语音模型会出现在应用现有的语音识别和语音合成模型选择器中。
4. 需要使用时，在对应选择器中选择 LiveKit 模型。添加服务商会保留现有的模型选择。

模型目录随 LobeHub 提供，不会从 LiveKit 获取模型定义。目录包含 Gemma、OpenAI、Deepgram、AssemblyAI、Cartesia、Fish Audio 和 Inworld 的部分现役模型。模型 ID 保留网关前缀，例如 `deepgram/nova-3` 和 `fishaudio/s2.1-pro`。

每个语音合成模型都提供了兼容的示例音色。你也可以指定该模型在 LiveKit Inference 中支持的其他音色 ID。直接服务商账户中的自定义或社区音色可能需要使用该服务商自己的集成。

## 排查问题

自托管部署可以通过 `LIVEKIT_INFERENCE_API_KEY` 和 `LIVEKIT_INFERENCE_API_SECRET` 提供共享默认凭证，两项值必须来自同一个项目。用户配置的凭证对优先使用；两种方式都使用内置模型目录。详见[服务商环境变量说明](/zh/docs/self-hosting/environment-variables/model-provider#livekit-inference)。

认证失败时，请确认两项凭证来自同一个 LiveKit Cloud 项目，并且项目已开通 Inference。Fish Audio、Cartesia 或 OpenAI 的 API Key 不能用于 LiveKit Inference 认证。

实时语音通话还需要部署 LiveKit 房间传输服务和 Agent Worker。服务商凭证用于模型推理；房间服务由部署管理员单独配置。
