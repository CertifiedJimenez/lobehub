# Use LiveKit Inference in LobeHub

[LiveKit Inference](https://docs.livekit.io/agents/models/inference/) provides language, speech recognition, and speech synthesis through a LiveKit Cloud project. Usage is billed through LiveKit Cloud; review the [current pricing](https://livekit.com/pricing) and your project's model availability.

1. Sign in to [LiveKit Cloud](https://cloud.livekit.io) and obtain your project's API key and matching API secret.
2. Open **App Settings → AI Providers → LiveKit**. Enter both **API Key** and **API Secret**, then enable the provider. Credentials are saved automatically.
3. Enable the desired models in the built-in model list. Use **Check** to verify a language-model request. Speech models appear in the app's existing speech recognition and text-to-speech model selectors.
4. Select a LiveKit model in the appropriate selector when you want to use it. Adding the provider preserves your existing model selections.

The catalog is bundled with LobeHub and does not fetch model definitions from LiveKit. It includes selected current models from Gemma, OpenAI, Deepgram, AssemblyAI, Cartesia, Fish Audio, and Inworld. Model IDs retain their gateway prefix, such as `deepgram/nova-3` or `fishaudio/s2.1-pro`.

Speech synthesis includes a compatible example voice for each model. You can provide another voice ID supported by that model through LiveKit Inference. Existing custom or community voices from a direct provider account may require that provider's own integration.

## Troubleshooting

Self-hosted deployments can provide shared defaults with `LIVEKIT_INFERENCE_API_KEY` and `LIVEKIT_INFERENCE_API_SECRET`. Set both values from one project. A user's configured credential pair takes priority. The built-in catalog is used in either case. See the [provider environment reference](/docs/self-hosting/environment-variables/model-provider#livekit-inference).

If authentication fails, verify that both credentials belong to the same LiveKit Cloud project and that the project has access to Inference. A direct Fish Audio, Cartesia, or OpenAI API key does not authenticate LiveKit Inference.

Live voice calls also require the deployment's LiveKit room transport and agent worker. Provider credentials configure model inference; your deployment administrator configures the room service separately.
